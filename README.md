# linktree.github.io

A modern, premium link-in-bio page featuring a glassmorphism aesthetic design.

## Features

- **Glassmorphism Design**: Modern frosted glass effects with backdrop blur for a premium, layered appearance
- **Modern Typography**: Poppins font family for clean, rounded aesthetics
- **Smooth Animations**: Enhanced hover effects with lift animations and colored drop-shadows
- **Mobile Responsive**: Optimized for all screen sizes with fluid width and balanced padding
- **Cozy Aesthetic**: Anime-style background with perfect contrast against the glass container
- **Performance Optimized**: Removed blur hacks in favor of native backdrop-filter for better performance

## Technologies Used

- HTML5
- CSS3 (with modern features like backdrop-filter)
- Google Fonts (Poppins)

## Design Highlights

- **Container**: Semi-transparent dark background with 16px blur, subtle border, and elegant shadows
- **Profile Section**: Glowing profile picture with soft white border and text shadows for readability
- **Link Cards**: Frosted glass effect with smooth transitions, lift animations on hover
- **Color Palette**: White/light backgrounds for standard links, pastel orange for special content
